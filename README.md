# Healthcare Data Analysis Project

## Project Overview

This project focuses on exploring and analysing healthcare data using Python.

The main objective is to investigate whether there is a statistical association between blood type and medical conditions.

## Dataset

The dataset contains healthcare information, including:

- Age
- Gender
- Blood Type
- Medical Condition
- Date of Admission
- Doctor
- Hospital
- Insurance Provider
- Billing Amount
- Admission Type
- Medication
- Test Results

## Technologies Used

- Python
- Pandas
- SciPy

## Data Exploration and Analysis

The project includes:

- Exploring the dataset structure and columns.
- Checking data types and missing values.
- Identifying duplicate records.
- Exploring the distribution of blood types.
- Exploring the distribution of medical conditions.
- Creating a cross-tabulation to compare blood types and medical conditions.
- Applying the Chi-square test of independence to investigate a possible statistical association.

## Results

The Chi-square test returned a p-value of approximately 0.477.

Since the p-value is greater than the significance level of 0.05, the analysis did not find statistically significant evidence of an association between blood type and medical condition categories in this dataset.
