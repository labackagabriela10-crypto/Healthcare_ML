# Healthcare_ML
# Healthcare Data Analysis Project

## Project Overview

This project focuses on exploring and analysing healthcare data using Python.

The main objective is to investigate whether there is a statistical association between blood type and medical conditions, with particular attention to diabetes.

## Dataset

The dataset contains healthcare information, including:

- Age
- Gender
- Blood Type
- Medical Condition
- Hospital
- Admission Type
- Medication
- Test Results
- Billing Amount

## Technologies Used

- Python
- Pandas
- SciPy

## Data Analysis

The project includes:

- Dataset exploration and inspection.
- Identification of missing values and duplicate records.
- Data cleaning and preparation.
- Analysis of blood types and medical conditions.
- Cross-tabulation to examine the distribution of medical conditions across blood types.
- Chi-square test of independence to investigate statistical associations.

## Results

The Chi-square test did not identify a statistically significant association between blood type and medical condition in this dataset (p-value = 0.477).

This means that the analysis did not provide sufficient statistical evidence of an association between these variables.
